# Security

If you find a security problem in Erlangly, please tell us privately first: email **security@erlangly.com** with what you found and how to reproduce it. We'll reply within two business days, keep you posted while we fix it, and credit you in the release notes if you'd like.

Please don't open a public issue for security problems, and don't test against installs that aren't yours.

Fixes ship as new releases; `erlangly upgrade` installs them.
